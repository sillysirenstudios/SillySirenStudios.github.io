Common Questions

A diagram or equation shows as code. If Leaflet can't draw a Mermaid diagram or a math block, it shows the source instead. Check the syntax first; if it still won't render, send us the block and your macOS version.

Leaflet won't open a linked file. Leaflet only reads what you choose to open. A link to a file outside the folder you opened asks you to grant access first.
