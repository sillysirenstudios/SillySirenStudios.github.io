Capabilities

Open it. Read it.
That's the whole app.

Native, sandboxed, and focused on one job: showing your Markdown files the way they were meant to look.

📄

Opens Markdown Directly

Handles .md and .markdown files. It never silently steals the system default — you choose when Leaflet opens a file.

🧾

Full GitHub-Flavored Markdown

Headers, lists, tables, task lists, strikethrough, autolinks, blockquotes, images, and fenced code blocks with syntax highlighting.

📈

Mermaid Diagrams

Fenced mermaid blocks render as diagrams, using a copy of mermaid.js bundled inside the app — never fetched from the network.

🌗

Dark Mode

Follows your system appearance, so documents look right day or night.

👁

Read-Only by Design

There is no save path at all. Leaflet reads the files you open and never writes to or modifies them.

🔒

Zero Network Entitlement

Leaflet is sandboxed with no network access, full stop. Your files never leave your Mac — a deliberate, verifiable guarantee.
